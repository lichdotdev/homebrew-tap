# lichdotdev/homebrew-tap

Homebrew cask for [lich](https://github.com/lichdotdev/lich), macOS on Apple
Silicon and Intel.

```bash
brew install --cask lichdotdev/tap/lich
```

The cask is rendered by lich's release pipeline and pushed on each tag, from
`build/darwin/homebrew/lich.rb.tpl` in [lichdotdev/lich](https://github.com/lichdotdev/lich).
Edit the template in the project, never the copy in this repository: the next
release overwrites it.
